Tu bóveda se sincroniza como un repositorio git en el almacenamiento que elijas: GitHub, GitLab, Codeberg o tu propio servidor. No hay cuenta de Baluard ni servidor central. Esta sección cubre cómo funciona la sincronización, cómo elegir un proveedor y cómo proteger la cuenta del proveedor.

1. [Sincronizar tu bóveda](@/introduction/sync/syncing-your-vault.es.md): cómo funciona git sync y qué puede ver tu proveedor.
2. [Elegir un proveedor de Git](@/introduction/sync/git-providers.es.md): GitHub, GitLab, Codeberg o tu propio servidor; límites de tamaño, pros y contras.
3. [Autenticación de dos factores (2FA) y tu proveedor de Git](@/introduction/sync/provider-2fa.es.md): por qué la 2FA vive en el proveedor y no dentro de tu bóveda.
4. [El agente SSH](@/introduction/sync/ssh-agent.es.md): deja que la terminal y git firmen con las claves SSH de tu bóveda; configuración para Linux y macOS.
