Baluard se distribuye como paquetes del sistema para Linux, un instalador para Windows y un zip de aplicación para macOS. Esta sección cubre los pasos de instalación de cada plataforma y los dos avisos de descarga que puedes encontrar: SmartScreen en Windows y Gatekeeper en macOS.

1. [Instalación](@/introduction/install/installation.es.md): repositorios de paquetes, descargas directas y la CLI.
2. [El aviso de SmartScreen en Windows](@/introduction/install/windows-smartscreen.es.md): por qué Windows muestra "Windows protegió tu PC" y cómo continuar.
3. [El aviso de Gatekeeper en macOS](@/introduction/install/macos-gatekeeper.es.md): por qué macOS dice que no puede verificar la aplicación y cómo abrirla de todos modos.
