The `baluard` CLI gives you full vault access from the terminal and lets AI coding agents run commands or render configuration templates without ever receiving plaintext secret values.

1. [Everyday CLI vault reference](@/cli-and-agents/cli-reference.md): create, unlock, search, edit, generate passwords, and sync from the terminal.
2. [Agentic workflows with the CLI](@/cli-and-agents/agentic-workflows.md): `baluard://` references, `baluard run`, `baluard inject`, `baluard read`, and approvals.
3. [Browser automation with secrets](@/cli-and-agents/browser-automation.md): let an AI agent fill web forms while the values stay out of the agent's context.
4. [MCP server (`baluard mcp`)](@/cli-and-agents/mcp-server.md): connect coding tools like Claude Code or Cursor to Baluard with read-only, human-approved access.
