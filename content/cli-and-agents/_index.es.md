El CLI `baluard` te da control completo de la bóveda desde la terminal y permite que agentes de código con IA ejecuten comandos o rendericen plantillas de configuración sin recibir jamás valores secretos en texto plano.

1. [Referencia diaria del CLI](@/cli-and-agents/cli-reference.es.md): crea, desbloquea, busca, edita, genera contraseñas y sincroniza desde la terminal.
2. [Flujos agénticos con el CLI](@/cli-and-agents/agentic-workflows.es.md): referencias `baluard://`, `baluard run`, `baluard inject`, `baluard read` y aprobaciones.
3. [Automatización de navegador con secretos](@/cli-and-agents/browser-automation.es.md): deja que un agente de IA complete formularios web mientras los valores quedan fuera del contexto del agente.
4. [Servidor MCP (`baluard mcp`)](@/cli-and-agents/mcp-server.es.md): conecta herramientas de código como Claude Code o Cursor con acceso de solo lectura aprobado por ti.
